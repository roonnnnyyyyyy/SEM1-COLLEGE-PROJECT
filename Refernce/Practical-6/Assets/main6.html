Practical 7: Multimedia & Image Optimization

Image Optimization (4 Techniques)

1. Format Change (WebP)

Using modern .webp format to compress file size.

2. Fixed Dimensions

Defined width and height to stop layout shifting.

3. Lazy Loading

Image loads only when we scroll down to it.

4. Responsive (Fluid)

Image shrinks or grows based on screen size.
